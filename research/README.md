
## 무엇으로 쟀나 (두 시장 공통 규칙)

* 매수는 신호 **다음 거래일 시가**, 매도는 정해진 거래일 뒤 **종가**
* 3개월=60거래일 · 6개월=120거래일 · 1년=250거래일
* 52주 고가 = 그날 High까지 포함한 **252거래일 최대값**. 앞을 훔쳐보지 않는다
* 성적은 **가운데 값과 승률**을 같이 본다. 평균만 보면 몇 종목의 큰 상승에 속는다
* **기준선('아무 날 아무 종목이나 샀으면')을 반드시 같이 낸다.**
  살아남은 회사만 보는 치우침이 양쪽에 똑같이 걸려 상쇄된다
* 교차 검증 — 기간을 반으로 갈라 앞뒤 따로 재고, **사건수**를 같이 적는다
