# TOMORROW_USAGE_GUIDE.md — 다음 날 사용 가이드 (간편 저장용 텍스트 예시)

작성일: 2026-07-06

이 문서는 "브리핑 붙여넣기" 탭의 **간편 저장용 텍스트(자동 채우기)** 입력란에 그대로
붙여넣을 수 있는 실전 예시를 모아둔다. `docs/BRIEFING_LOGIC.md`의 단계/신호분류/
단타·스윙 분리 기준을 실제 텍스트 형식으로 옮긴 것이다.

## 종목 줄 형식 (다시 정리)

- 구분자는 `/`
- **6개 필드(기존, 매매유형 없음)**: `종목명 / 티커 / market / 판정 / 신호 분류 / 이벤트명`
  → 이 경우 `trade_mode`는 자동으로 `공통`으로 저장된다.
- **7개 필드(신규, 매매유형 포함)**: `종목명 / 티커 / market / 매매유형 / 판정 / 신호 분류 / 이벤트명`
  → `매매유형`은 `단타` / `스윙` / `공통` 중 하나.

## 예시 1 — 09:40 장초반 (기존 6필드 형식)

```
[기본]
시장 범위: KR
시점 구분: 장중
브리핑 단계: 09:40 현재 장초반 수급 조짐
신호 분류: 재확인 신호

[오늘의 결론]
09:40 현재 기준 장초반 수급 조짐: 반도체가 가장 강하다. 삼성전자는 추천 후보 유지. SK하이닉스와 한화오션은 감시. 현대차와 현대모비스는 확인 필요.

[종목]
삼성전자 / 005930.KS / KR / 추천 후보 / 재확인 신호 / 실적 기대 + 장초반 강세 확인
SK하이닉스 / 000660.KS / KR / 감시 / 재확인 신호 / 반도체 동반 상승이나 삼성전자 대비 주도 약함
한화오션 / 042660.KS / KR / 감시 / 늦은 신호 / 장초반 급등 후 발견
한화에어로스페이스 / 012450.KS / KR / 감시 / 재확인 신호 / 방산 대장주 감시
현대차 / 005380.KS / KR / 확인 필요 / 미분류 / 자동차 섹터 주도 근거 약함
기아 / 000270.KS / KR / 확인 필요 / 미분류 / 자동차 섹터 주도 근거 약함
현대모비스 / 012330.KS / KR / 확인 필요 / 미분류 / 자동차 부품 섹터 주도 근거 약함
```

## 예시 2 — 13:10 오후 지속/반전 판단, 단타/스윙 분리 (신규 7필드 형식)

같은 종목이라도 단타 판단과 스윙 판단을 각각 한 줄씩 따로 적는다.

```
[기본]
시장 범위: KR
시점 구분: 장중
브리핑 단계: 13:10 오후 지속/반전 판단
신호 분류: 재확인 신호

[오늘의 결론]
13:10 현재 기준으로 단타와 스윙을 분리한다. 단타는 장중 생존력, 스윙은 종가 이후 지속성을 본다.

[종목]
삼성전자 / 005930.KS / KR / 단타 / 보류(선반영) / 재확인 신호 / 나스닥100 선물 약세 + 장중 고점 대비 밀림
삼성전자 / 005930.KS / KR / 스윙 / 감시 / 재확인 신호 / 종가 확인 전까지 판단 보류
SK하이닉스 / 000660.KS / KR / 단타 / 보류(선반영) / 재확인 신호 / 반도체 대형주 고점 대비 밀림
SK하이닉스 / 000660.KS / KR / 스윙 / 감시 / 재확인 신호 / 일봉 추세와 종가 확인 필요
현대차 / 005380.KS / KR / 단타 / 감시 / 재확인 신호 / 자동차 섹터 강세 확인
현대차 / 005380.KS / KR / 스윙 / 감시 / 재확인 신호 / 종가 유지 시 스윙 후보 가능
기아 / 000270.KS / KR / 단타 / 감시 / 재확인 신호 / 자동차 섹터 강세 + 시총 대비 탄력성
기아 / 000270.KS / KR / 스윙 / 확인 필요 / 재확인 신호 / 종가 강하면 스윙 후보 가능
현대모비스 / 012330.KS / KR / 단타 / 감시 / 재확인 신호 / 자동차 부품 섹터 탄력성
현대모비스 / 012330.KS / KR / 스윙 / 감시 / 재확인 신호 / 거래대금과 종가 유지 확인
한화오션 / 042660.KS / KR / 단타 / 감시 / 늦은 신호 / 09:40 이후 발견 시 추격 주의
한화오션 / 042660.KS / KR / 스윙 / 감시 / 늦은 신호 / 조선 섹터 지속성 확인
한화에어로스페이스 / 012450.KS / KR / 단타 / 감시 / 재확인 신호 / 방산 대장주 흐름 확인
한화에어로스페이스 / 012450.KS / KR / 스윙 / 감시 / 재확인 신호 / 방산 재료 지속성 확인
```

> 참고: 원본 요청 예시의 판정 문구 "보류"와 "관심 후보"는 앱의 `verdict` 5종 고정값
> (추천 후보 / 감시 / 확인 필요 / 보류(선반영) / 제외)에 정확히 없는 표현이라, 자동
> 채우기 시 인식하지 못하면 안전하게 "확인 필요"로 대체되고 경고가 표시된다. 위 예시는
> 실제 저장 시 그대로 통과하도록 "보류(선반영)"로 맞춰 적었다. "관심 후보"도 마찬가지
> 이유로 "확인 필요"로 바꿔 적었다 — verdict 자체를 늘리는 것은 이번 수정 범위가 아니다.

## 참고

- `시점 구분` 줄은 파싱만 되고 저장에는 쓰이지 않는다 — `timing_class`는 저장 시각
  기준 자동 분류라는 기존 규칙 때문이다 (경고 문구로 안내됨).
- 매매유형은 화면에서 `[단타] 종목명 / 판정`, `[스윙] 종목명 / 판정` 형태로 표시된다.
