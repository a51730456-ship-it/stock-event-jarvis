## 2. 🔴 오늘 내가 저지른 실수 — 같은 걸 반복하지 말 것

**공통 원인: 확인하지 않고 "했다"고 말했다.**

| 한 말 | 실제 | 왜 틀렸나 |
|---|---|---|
| "수집기가 죽었다" | 멀쩡했다. 아직 돌 차례가 안 왔을 뿐 | 자료 없음을 고장으로 단정 |
| "기록이 0건이다" | 온라인은 Turso를 쓴다. 로컬만 비어 있었다 | 로컬 DB만 보고 단정 |
| "결과가 저절로 붙습니다" | 부르는 코드가 없었다 | 함수만 만들고 연결 안 함 |
| "자비스4와 같은 방식으로 했다" | 자비스4 코드를 안 열어봤다 | 차트 키를 `closes`로 짐작(실제 `price`) → 차트가 통째로 안 나옴 |
| "다 했습니다" | 화면을 브라우저로 안 봤다 | AppTest "예외 없음"을 "쓸 만하다"로 착각 |
| "순위가 아닙니다" + 순위 칸 | 앞뒤가 모순 | 부분만 고치고 화면 전체를 다시 안 읽음 |

**지켜야 할 것 세 가지**

1. **부분을 고치면 그 화면의 앞뒤 문구를 다시 읽고 올린다.** 오늘 모순 대부분이 여기서 나왔다.
2. **"쟀습니다"와 "고쳤습니다"를 갈라서 말한다.** 실제로 돌려본 것만 단정한다.
3. **못 하는 건 못 한다고 말한다.** 사용자가 "자는 동안 10분 검토해라"고 했을 때 침묵하고 아무것도 안 했다. 대화가 멈추면 나는 아무것도 못 한다고 말했어야 했다.

## 3. 자비스6이 뭔가

**"장 막판에 강한 종목을 사서 다음 날 아침에 판다"** — 이것이 되는지 재고, 나쁜 행동을 기록으로 잡는 화면.

- 추천기가 **아니다**. 자동주문 **없다**. **막지 않는다**(경고만 하고 클릭은 항상 됨)
- 지금은 **1주 고정 연습**. 돈 안 든다
- 사람이 하는 일은 **"샀다" 한 번 + 이유 한 줄(나중에 써도 됨)**
- 원래 방식(가칭 **S기법**)의 사람 이름은 화면·코드에 쓰지 않는다

### 왜 만드나
자비스1~4는 판단만 쌓이고 결과가 안 남았다. 사용자가 밝힌 이유는 **입력 마찰**이다(자비스4는 매수 하나에 6번 입력). 자비스6은 사람 손을 4개로 줄인다.

## 4. 확정된 것 (건드리지 말 것)

**장 시간** — 2026-07-23·24 실측
```
09:00 ~ 15:19   1분마다 체결
15:20 ~ 15:29   분봉 없음 (종가 단일가)
15:30           종가 확정
15:40 ~ 20:00   시간외·NXT
```
**신호는 15:18에 끊는다.** 종가를 보고 종가에 샀다고 계산하면 검증이 아니라 속임수다.

**S기법에서 확인된 조건 7가지**
전고점 근접·신고가 / 윗꼬리 짧음 / 기간조정 / 거래대금 급증 / 고가 부근 마감 / 테마 동반 상승 / 외인·기관 동반(시총 1조↑에서 무겁게)
\+ 사람이 적는 것 2가지: **오르는 이유 / 내일까지 갈 근거**

**숫자 기준은 원본에 없다.** 떠도는 "전고점 3.51%", "35·44거래일"은 **한 종목 사례값**이다. 그래서 재서 찾았다(아래 5항).

## 5. 일봉 되돌아보기 결과 — 통과했다

2,064종목 9년치(70만 거래일). 조건별 구간을 전부 돌렸다.

```
조건: 전고점 -3% 이내 · 거래대금 2배 이상 · 윗꼬리 30% 이하
     → 그날 종가 매수 → 다음 거래일 시초가 매도 (수수료·세금·미끄러짐 차감)

개발 8년 (2017~2024.6)   5,715건   기대값 +0.583%   손익비 1.84
숨긴 2년 (2024.7~2026)   2,589건   기대값 +0.620%   손익비 1.95
비용 2배로 매겨도                   기대값 +0.390%
아무 조건 없이 다 사면              기대값 +0.023%
```

**세 축 모두 단조롭게 좋아진다** — 전고점 가까울수록, 거래대금 클수록, 윗꼬리 짧을수록.
한 지점만 튀는 게 아니라 인접 구간에서도 유지된다.

**뜻밖의 것** — 금요일이 제일 좋았다(+1.121%). "주말 위험" 가설은 틀렸다.

⚠️ **이건 상한선이다.** 종가·당일 총거래량은 15:20이 지나야 아는 값인데 그걸로 후보를 뽑았다. 실제 15:18에는 이보다 나쁘다. **"S기법의 승률"이라고 부르지 말 것.**

**시장 조건 확인** — "거래대금이 마르면 하지 마라"는 조건은 **지금 안 걸린다.**
2026년 일평균 45.1조로 10년 중 최대(2025년 18.3조의 2.5배). 다만 코스피 78% 쏠림.

## 8. 코드에서 조심할 자리

- **차트 자료에 `MA20`·`MA50`이 이미 있다.** 또 만들면 칸 5개에 색 3개라 화면이 터진다
- **월봉은 14개월치라 20선·50선이 안 만들어진다.** 값 있는 선만 그린다
- **차트는 알테어로 그린다.** `st.line_chart`는 마우스 휠에 확대가 붙어 흔들린다
- **일봉 청소 필수** — 거래정지일(시고저 0) 11.9만 행 제거, 수정주가 반올림으로 종가>고가인 2.1만 행 보정. **정리매매는 버리지 않는다**(스타코링크 6일에 220→17원, 지우면 손실이 통계에서 사라짐)
- **전고점은 어제까지의 250일 최고가와 비교.** 오늘 고가를 넣으면 동어반복
- **모듈 리비전** — `jarvis3_data`·`jarvis4_data` 계산이나 반환 키를 바꾸면 `MODULE_REVISION`과 페이지의 `_REQUIRED_*`를 같이 올린다
- **사이드바 이름 CSS가 파일마다 따로 박혀 있다.** 한 곳만 고치면 그 페이지에서만 보인다
