## 2. 반드시 알고 가야 할 검증 결과

### 2-1. 50일선 신호는 "수익 예측"이 아니라 "손실 방어"다

지수 일봉 21년치로 직접 쟀다 (코스피 5,253일 · S&P500 5,357일, 2005-03~2026-06).
그날까지 자료로만 신호를 만들고 20일 뒤 종가로 성적을 냈다. 부트스트랩 1,500회.

```
미국 S&P500   50일선 위 +0.65%  /  아래 +1.12%   ← 수익은 아래가 나음
              아래일 때 10%↓ 확률 3배, 최악1% 손실 2배, 출렁임 1.7배
한국 코스피    50일선 위 +1.01%  /  아래 +0.83%   ← 우연과 구분 안 됨
              깨짐 방어도 약함 (-15.2% vs -15.5%)
```

**결론: 미국은 방어 장치로 잘 듣고, 한국은 약하다.**
이 내용이 `method_help.py`에 화면 문구로 들어가 있다. **숫자를 고치려면 반드시 다시 재고 고칠 것.**

### 2-2. 종목으로 과거 검증하면 안 된다 (오늘 크게 데었다)

테마 구성종목으로 백테스트하면 **오늘 잘나가는 종목만 모으는 편향**이 낀다.

- 오늘 한국 테마 목록 = 윤활유·해운·카지노·신규상장 (폭락 뒤 방어주)
- 2025~26년 두 배 오른 주도주는 순위에서 밀려나 표본에 없음
- 그래서 코스피가 +75% 오른 기간인데 표본 성적은 −0.58%로 나왔다

미국 `US_THEMES`도 같은 병 — 손으로 고른 목록이라 "나중에 성공한 종목"만 들어 있다.

**제대로 재려면 "그 시점에 상장돼 있던 전체 종목"이 필요하다. 아직 안 했다.**
