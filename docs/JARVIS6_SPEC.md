# 자비스6 — 종가 관찰 (연구 명세)

작성 2026-07-26. **아직 만들지 않는다.** 만들 가치가 있는지 재는 단계다.

가칭 **S기법** = 실전투자대회 우승자의 종가매매. 제품 화면·코드에는 사람 이름을 쓰지 않는다.
검증 안 된 숫자에 실제로 증명한 사람 이름을 달면 없는 신뢰가 생긴다.

---

## 1. S기법에서 확인된 것

여러 2차 자료(자막 노트·티스토리 복기·실사용자 기록)에서 반복 확인된 것만.

- 장 마감 30분이 승부처. 호가창보다 추세와 거래량
- **싸게 사려고 일찍 사지 않는다. 확인하고 늦게 산다**
- 조건: 재료 있음 · 재료가 내일까지 · 거래대금 급증 · 전고점 근접/신고가 ·
  기간조정으로 매물 소화 · 짧은 윗꼬리 양봉 · 장 막판 저점 상승 · 대형주 외인기관 동반
- **오르는 이유를 모르면 뇌동매매** (가장 강하게 반복됨)
- 시간외에서 매수가 이탈하면 그날 손절. 2~3% 수익이면 일부 익절
- 익일 시초가 1/3~1/2, **09:05 전량**. 더 올라도 안 쫓는다
- **손실 중 물타기 금지**
- 시장이 안 맞으면 쉰다

### 확인 안 된 것 — 숫자가 하나도 없다
전고점 몇 % · 조정 며칠 · 거래대금 몇 배 · 윗꼬리 몇 % · 손절률 · 승률.
떠도는 3.51%, 35·44거래일은 **한 종목 사례값**이지 기준이 아니다.
→ **숫자는 정하고 시작하지 않는다. 재서 찾는다.** 이 프로젝트의 전부다.

```

15:20 ~ 15:29   분봉 없음 — 종가 단일가 구간
15:30           종가 확정 (삼성전자 278만주가 여기서 한 번에)
시간외/NXT      15:40 ~ 20:00
```

**신호 확정은 15:18.** 15:20 이후 값은 신호 계산에 절대 넣지 않는다.
종가를 보고 종가에 샀다고 계산하면 검증이 아니라 사기다.

**증권사 API는 쓰지 않는다.** 사용자가 증권계좌를 열 수 없다. 이 항목은 다시 꺼내지 않는다.

### 수급 대체안
당일 "누가 샀나"는 못 본다. 대신 **"몰리고 있다는 흔적"**을 쓴다.
거래대금 배수 · 장 막판 저점 상승 · 테마 동반 상승.
화면에는 `외인·기관 동반 4일/5일 (어제까지)`로 적는다. **오늘 것인 척하지 않는다.**

## 4. 입력

**자비스가 자동** — 가격·거래대금·고가저가·시총·전고점·조정일수·테마·수급(전일)·시장·시간외·익일결과

**사람이 넣는 것 4개뿐**
```
1. 왜 오르나              한 줄
2. 내일까지 갈 근거        한 줄
3. 틀렸다고 볼 조건        한 줄
4. 샀다 / 안 샀다          버튼
```
날짜·가격·조건 숫자는 묻지 않는다. 자비스가 이미 안다.
자비스1~4에 기록이 안 쌓인 이유가 **입력 마찰**이었다(사용자 확인).

## 5. 가장 중요한 세 가지

1. **15:18에 끊는다** — 종가를 모르는 시점에서 판단을 굳힌다
2. **세 줄 안 쓰면 못 산다** — 점수 100점이어도 차단. S기법 핵심이자 복기의 전제
3. **숫자를 지금 정하지 않는다** — 구간을 다 돌려 어디서 무너지는지 본다.
   한 지점에서만 좋고 인접 구간에서 무너지면 우연이다. 채택하지 않는다

---

## 6. 차단하지 않는다 — 기록하고 나중에 비교한다

**2026-07-26 사용자 지시로 바꿨다. 하드 차단은 넣지 않는다.**

원래 근거 미입력·추격 등을 막으려 했으나, 그게 자비스 원칙과 어긋난다.

> *"통계 근거 없는 차단 추가 금지"*
> *"필터 준수 매매 vs 무시 매매 손익 차이를 숫자로 증명하는 것이 앱의 핵심"*

막으면 그 비교를 **아예 못 한다.** 근거 없이 산 것도 기록해야 나중에
`근거 쓴 매매 18번 중 11번 이익 / 근거 없는 매매 9번 중 2번 이익`이 나온다.
숫자가 나오면 잔소리보다 낫다. 차단은 그 숫자가 나온 뒤에 검토한다.

**경고는 표시하되 클릭은 항상 된다.** 무시하면 `경고 무시`로 태그만 남는다.

### 클릭 한 번으로 끝난다
`샀다`를 누르면 그 순간 스냅샷을 통째로 저장한다 — 날짜·시각·가격·전고점 거리·
거래대금 배수·윗꼬리·종가위치·수급·테마 상태·시장 상태. **아무것도 묻지 않는다.**

재료 세 줄은 **나중에 써도 되고 안 써도 된다.** 안 쓰면 `근거 없음` 태그만 붙는다.
실제로 안 샀어도 `연습`으로 저장되고 익일 결과가 자동으로 붙는다. 계좌와 무관하다.

사용자가 하는 일은 **장 막판에 화면 열고 괜찮아 보이는 것 한 번 누르기**가 전부다.
안 누른 날은 그냥 넘어가고 자료는 알아서 쌓인다.

### 그래도 재는 것
전고점 거리·기간조정·거래대금 배수·윗꼬리·저점 상승·수급·테마 동반은
**전부 저장한다.** 차단에 쓰지 않을 뿐이다. 나중에 조건별 성과를 가르는 재료다.

## 7. 자비스4 기준을 물려받지 않는다

자비스4의 `테마 70점 / 종목 70점 / 시장 50점`은 코드 주석에 근거가 적혀 있다 —
*"실측(2026-07-22 강세장)에서 만점이 여러 개 나와 변별이 안 되던 것을 보고 넓혔다."*
**하루 돌려보고 눈대중으로 맞춘 값이다.** 성과로 검증한 적 없다.

자비스6은 처음에 점수를 만들지 않는다. **순위와 백분위, 원자료만 저장**한다.
`강함 70점` 대신 `거래대금 상위 2% · 테마 내 1위 · 14:30 이후 +2.1%`.
