# 한국장 두 갈래 — 전면 재측정 (2026-08-07)

자비스4의 '상승장(신고가 눌림매수)'과 '급락 후 반등장(낙폭종목)'의 **그물과 배점을
통째로 다시 잡았다.** 2026-08-01 판은 두 가지가 어긋나 있었다.

1. **잰 대상이 화면과 달랐다.** 시총 상위 197종목으로 쟀는데, 화면이 실제로 뒤지는
   것은 네이버 테마 266개의 **2,272종목**이다. 미국에서 같은 어긋남을 고치자 결론이
   뒤집힌 적이 있다(2026-08-06).
2. **자르는 날 하나에 기댔다.** 12년을 통째로 한 번만 쟀다. 그러면 한쪽 시기에만
   통한 값이 "12년 내내 좋았다"처럼 보인다.

## 어떻게 쟀나

| | |
|---|---|
| 종목 | 네이버 테마 266개의 **2,272종목** (`data/kr_roster.json`, 2026-08-07 찍음) |
| 기간 | **2014-05-19 ~ 2026-08-07 · 3,000거래일** |
| 자료 | 네이버 일봉(`fchart.stock.naver.com`) · 코스피 지수도 같은 곳 |
| 매수 | 신호가 난 날의 **다음 거래일 시가** |
| 매도 | 정해진 거래일 뒤 **종가** |

**앞을 훔쳐보지 않는다.** 52주 고가는 하루 밀어서 그날까지의 값만 쓴다.

**수정주가 확인함** — 546만 개 등락 중 하루 45% 넘게 빠진 자리가 31개(0.0006%)뿐이다.
액면분할을 반영 안 한 시세라면 정확히 1/2·1/5로 떨어지는 자리가 수천 개 나온다.

### 잣대 — 창을 밀며 100번 넘게 잰다

**3년짜리 창을 한 달씩 밀면서** 매번 다시 재고, **창 2·3·4년 모두에서** 승률과
수익률이 둘 다 65% 넘는 창에서 이겨야 인정한다. 자르는 날을 사람이 고르지 않으므로
고르는 자의성이 없다. 같이 보는 **가장 나빴던 창**이 실제 위험이다.

**비교 상대**
* **그물을 잴 때** — 그날 같은 울타리(거래대금 문턱 안) 전체
* **배점을 잴 때** — **같은 그물 안의 나머지**. 배점은 그물에 걸린 것 중 순위를
  매기는 값이기 때문이다. 여기를 틀리면 '그날이 어떤 날이었나'를 재게 된다
  (2026-08-07에 실제로 틀렸다).

## 그물 — 격자로 다 재서 골랐다

상승 **192조합** · 급락 후 반등 **240조합**을 재서 상승 41개 · 급락 66개가 합격했다.
(미국은 같은 방법으로 상승 144조합 중 **0개**가 합격했다.)

### 갈래 1 — 상승장 (신고가 눌림매수)

**거래대금 50억↑ · 52주 신고가 뒤 3~10거래일 · 그 고점 대비 −4~−6% · 250거래일 보유**

| | 이 규칙 | 아무 종목이나 |
|---|---|---|
| 거래 | 7,410건 (신호 난 날 2,310일) | |
| 승률 | **43.4%** | 35.1% |
| 가운데 값 | **−6.6%** | −14.0% |
| 기준선보다 나았던 해 | **11년 중 9년** | |
| 기준선보다 나았던 창 | **321개 중 321개** (가운데 +8.7%p · 최악 +0.0%p) | |

**절대로는 여전히 잃는다.** 아무 종목이나 사면 −14.0%인데 규칙대로 고르면 −6.6%다.
**덜 잃는 것**이지 버는 것이 아니다. 화면에도 그대로 적었다.

**거래대금 50억 문턱이 결정적이다.** 그 아래에서는 앞 시기에 졌다. 격자 상위 15개가
전부 500억↑이었지만, 500억을 그물로 쓰면 하루에 한 종목도 안 걸려 화면이 빈다.
그래서 **문턱은 50억, 500억은 배점(30점)**으로 나눴다.

### 갈래 2 — 급락 후 반등장 (낙폭종목)

**코스피가 고점 대비 −15% 아래로 내려간 국면의 가장 깊었던 날 ·
거래대금 50억↑ · 종목 고점 대비 −40~−60% · 20거래일 보유**

| | 이 규칙 | 그날 아무 종목이나 |
|---|---|---|
| 거래 | 3,739건 (신호 **29번**) | |
| 승률 | **66.6%** | 62.1% |
| 가운데 값 | **+6.1%** | +4.1% |
| 기준선보다 나았던 해 | **8년 중 7년** | |
| 기준선보다 나았던 창 | **306개 중 306개** (가운데 +9.1%p · 최악 +1.4%p) | |

**신호 잡는 법을 바꿨다.** 옛 규칙 '코스피가 처음 반등한 날'은 12년에 **여덟 번**
뿐이었다. '그 국면에서 가장 깊었던 날'로 바꾸니 **스물아홉 번**으로 늘고 성적도 나았다.

**얕은 갈래는 뺐다.** −30~−40%는 2026-08-01 측정에서 이미 기준선에 졌는데 화면에
남아 있었다. 이번 격자에서도 붙지 않았다. **−40~−60% 하나만 쓴다.**

## 배점 — 새 그물 위에서 다시 쟀다

옛 배점은 옛 그물에서 잰 것이라 통째로 무효다. 후보 17개를 같은 방법으로 다시 쟀다.
칸은 '승률로 이긴 창% / 수익률로 이긴 창%'.

### 상승장 (그물 안 8,415자리)

| 항목 | 점수 | 2년 | 3년 | 4년 | 최악 창 |
|---|---|---|---|---|---|
| 거래대금 (500억↑ 만점) | **30** | 100/90 | 100/100 | 100/100 | +4.9%p |
| 같은 테마 동반 (3개↑ 만점) | **25** | 85/95 | 96/100 | 100/100 | −0.3%p |
| 많이 흔들리지 않나 (하루 6%↑면 0점) | **25** | 7/0 | 2/1 | 0/0 (거꾸로) | −30.9%p |
| 60일에 **너무 오르지** 않았나 (40%↑면 0점) | **20** | 17/13 | 28/21 | 31/15 (거꾸로) | −19.2%p |
| ~~거래대금 평소 위 연속~~ | 0 | 74/73 | 63/68 | 52/59 | |

**60일 상승폭은 방향이 정반대였다.** 2026-08-01에는 40% 넘게 오른 쪽에 만점(25점)을
줬는데, 창을 밀며 다시 재니 그쪽이 대부분의 창에서 졌다. 앞뒤로 갈라 재지 않아
놓친 것이다. **변동성도 0점에서 25점으로 바뀌었다** — 하루 6%가 넘으면 295개 창 중
거의 전부에서 졌다.

### 급락 후 반등장 (그물 안 3,907자리)

| 항목 | 점수 | 2년 | 3년 | 4년 | 최악 창 |
|---|---|---|---|---|---|
| 최근 11일에 안 올랐나 (5%↑면 0점) | **30** | 100/100 | 99/99 | 99/99 | −2.9%p |
| 60일에 안 올랐나 (40%↑면 0점) | **25** | 100/100 | 100/100 | 100/100 | +2.8%p |

| 사고팔기 쉬운가 | **20** | 성적 예측이 아니라 '살 수 있는가' | | | |
| ~~낙폭 갈래~~ | 0 | 그물로 이미 한 번 썼다 | | | |

**가장 큰 값은 '이미 반등을 시작한 종목은 사지 마라'다.** 최근 11일에 5% 넘게 오른
종목은 창 306개 중 거의 전부에서 졌다(가운데 −20.9%p · 가장 나쁜 창 −43.7%p).

**미국과 정반대인 곳** — 미국 급락 후 반등장에서는 테마 동반 개수가 붙지 않았다
(그물의 68%가 3개 이상이라 못 가른다). 한국은 붙는다. 한국 테마가 266개로 잘게
쪼개져 있어서로 보인다.

## 못 잰 것 · 한계

* **거래비용·세금이 안 들어갔다**(2026-08-07 상하님 지시로 뺐다).
* **테마 명부는 오늘 것이다.** 12년 전에 그 종목이 그 테마였는지 알 수 없다
  (네이버가 과거 구성을 안 준다). '같은 테마 동반' 항목은 이 한계를 그대로 안고
  있고, **창을 밀어도 이 한계는 드러나지 않는다.**
* **살아남은 종목만 봤다.** 기준선에도 똑같이 걸려 상당 부분 상쇄되지만 완전하지 않다.
* **후보를 예순 개 넘게 훑었다.** 합격선 65%로 그렇게 많이 훑으면 값 없는 것도 몇 개는
  붙는다. 그래서 창 길이 셋과 두 잣대를 모두 요구했지만, 완전히 걸러지지는 않는다.

## 다시 재려면

```
python kr_roster_snapshot.py            # 오늘의 명부를 찍는다
python research/kr_fetch_daily.py       # 명부 종목 일봉 (research/_data, 저장소에 안 올림)
python research/kr_fetch_index.py       # 코스피·코스닥
python research/kr_measure.py load      # 넓은 표로 묶기
python research/kr_net_grid.py up       # 그물 격자 (상승)
python research/kr_net_grid.py down     # 그물 격자 (급락 후 반등)
python research/kr_score_new.py         # 새 그물 위 배점
```

결과가 바뀌면 `jarvis4_data.BREAKOUT_PULLBACK_RULE`·`CRASH_REBOUND_RULES`·
`BREAKOUT_SCORE_WEIGHTS`·`CRASH_SCORE_WEIGHTS`와 `method_help.KR_TEXT`,
그리고 이 문서를 **같이** 고친다. 화면 문구는 그 값을 읽어 쓴다.
