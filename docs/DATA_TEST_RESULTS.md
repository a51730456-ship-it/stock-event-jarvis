## 메모

- `yfinance`, `FinanceDataReader`는 KR/US 종목·지수 전부 조회 가능 — 향후 검증 단계에서
  주력 후보로 고려할 수 있음.
- `pykrx`는 개별 KR 종목(005930, 000660)은 정상 동작하지만, 이번 코드에서 사용한 KOSPI
  지수 코드(`"1001"`) 조회는 실패함. 원인 미조사 (코드값 또는 pykrx 내부 이슈로 추정).
  US 티커는 애초에 지원 대상이 아니므로 실패가 정상.
- `pykrx` 사용 시 콘솔에 `KRX_ID/KRX_PW 환경 변수 없음` 경고가 출력되지만, 개별 종목
  조회 자체는 경고와 무관하게 정상 동작함 (로그인 불필요한 공개 데이터로 보임).
- 이 결과는 1단계 MVP(app.py/database.py) 개발을 막지 않으며, 실제 검증 기능을 만들
  때(다음 단계 이후) 참고용으로만 사용한다.
