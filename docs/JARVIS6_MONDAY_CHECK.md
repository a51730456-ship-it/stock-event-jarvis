# 월요일 아침 혼자 확인하는 법

**클로드 없이 눈으로만 합니다. 3분이면 끝납니다.**
고치지 마세요. **보고 적어두기만** 하세요.

---

## 1. 자료가 생겼나 (제일 중요)

휴대폰이나 PC에서 GitHub 저장소를 엽니다.

```
github.com/a51730456-ship-it/stock-event-jarvis
```

`data` → `jarvis5` 폴더를 엽니다.

- **7월 27일 날짜가 붙은 파일이 있다** → 됐습니다. 끝.
- **없다** → 2번으로.

> ⚠️ Actions 탭의 **초록불은 믿지 마세요.** 자료를 못 내보내도 초록불이 뜹니다.
> 반드시 **파일이 있는지**로 봅니다.

확인 시각은 **09:30 이후**가 좋습니다. 08:55에 시작하지만 GitHub 사정으로
5~20분 늦게 출발합니다.

---

## 2. 없으면 — Actions 탭

저장소 위쪽 `Actions` → `자비스5 테마 수집`

- **빨간불** → 실패한 것입니다. 눌러서 **빨간 줄 하나만** 사진 찍어 두세요.
- **회색·아무것도 없음** → 아예 안 돈 것입니다. 그것도 적어두세요.

---

## 3. 화면 쪽 (여유 있으면)

자비스5 화면 → `종목행` 칸의 `· 고저 ○○%`

- **90% 넘으면** 정상입니다.
- 낮으면 그 숫자를 적어두세요.

---

## 고장이면 어떡하나

**월·화에는 아무것도 하지 마세요.** 고치려면 코드를 만져야 하고,
그건 토큰이 돌아온 뒤에 합니다.

대신 이 세 가지만 적어두시면 다음 대화방이 처음부터 다시 캐지 않습니다.

| 적을 것 | 예시 |
|---|---|
| 파일이 있었나 | "27일 파일 없음" |
| Actions 색 | "빨간불" 또는 "안 돌았음" |
| 고저 % | "62%" |

사진 한 장이면 더 좋습니다.
